# Amar Lifestyle

A free life tracker for a disciplined routine: daily tasks, a yearly routine, Discipline Points (DP) and monthly levels, money and budgets with locked edit history, tuition, reports with QR verification, and more.

Built by **Musfiqur Rahman**.

- Website: static files served by GitHub Pages (no build step).
- Data and login: Supabase (database rules enforce all scoring and money-lock rules on the server).
